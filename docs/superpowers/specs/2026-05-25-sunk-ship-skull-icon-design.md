# 击沉船只骷髅图标设计

## 背景

SeaWar 是一款海战棋类游戏。当前击中效果使用 CSS `::after` 伪元素展示 emoji 图标：
- 普通击中 (`hit`): 红色背景 + 💥 爆炸图标
- 船只击沉 (`sunk`): 深红色背景，**无图标**

用户反馈：击沉和击中的视觉区分不够明显，需要给击沉状态也加上一个独立的图标。

## 设计决策

### 方案选择

选择 **方案 A：纯 CSS 图标替换**，原因：
- 与现有 `hit` 的实现方式完全一致（`::after` + `content`）
- 改动范围最小，仅 2 行 CSS
- 无需修改 JS/TS 逻辑

### 具体实现

在 `public/style.css` 中，为 `.cell.sunk` 添加 `::after` 伪元素：

```css
.cell.sunk {
  background: #c0392b;
}

.cell.sunk::after {
  content: '\1F480';  /* 💀 */
}
```

击沉时，该船只所占的所有格子会自动显示 💀 骷髅图标，与 💥 击中形成清晰区分。

## 影响范围

- **文件**: 仅 `public/style.css`
- **逻辑**: 无改动，现有 `sunk` class 的添加逻辑已完善
- **兼容性**: 无影响
